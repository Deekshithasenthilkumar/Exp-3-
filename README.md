# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
To develop a Railway Management System to manage train details, passenger information, ticket booking, cancellation, and train schedules efficiently.

# SRS (Procedure):
1.Identify the requirements of the Railway Management System.

2.Define the purpose and scope of the system.

3.Identify the users such as Admin, Passengers, and Railway Staff.

4.Specify the functional requirements like train searching, ticket booking, ticket cancellation, and checking seat availability.

5.Specify the non-functional requirements such as security, reliability, performance, and usability.

6.Design the system based on the identified requirements.

7.Prepare the Software Requirement Specification (SRS) document.

8.Review and validate the SRS document to ensure all requirements are clearly defined.
